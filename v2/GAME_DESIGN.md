# PBK: Path to Black Belt — V2 Game Direction

## Core fantasy
A modern martial-arts game centered on authentic point sparring, eventually expanding into the full PBK world.

## First playable slice
One believable dojo. Bradley-style player character. One AI opponent. Fast, tactical point sparring.

## Combat identity
This is not a health-bar fighter.
- Punch: 1 point
- Kick: 2 points
- First to 5 wins the initial slice
- Scoring immediately pauses action
- Competitors reset to center
- Brief score callout
- Match resumes cleanly

## Desired feel
- Fast but readable
- Precise spacing
- Forward pressure matters
- Defensive side kick is useful but punishable
- Blitz should require correct range
- Whiffing should create vulnerability
- Blocking reduces easy scoring
- Camera should keep both fighters visible

## Future systems
PBK towns, schools, belts, instructors, bosses, forms, breaking, tournaments, apartments, shops, NPCs, money, vehicles, trophy case, belt rack.
