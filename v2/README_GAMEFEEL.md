# Milestone 1 — Game Feel Pass

Current focus: make one PBK sparring match feel like a real game before expanding the world.

Desktop controls:
- WASD: move
- J: punch
- K: side kick
- U: round kick
- Space: blitz entry
- L: block
- Q: angle-out escape
- R: restart

Mobile keeps movement and the major attack/block actions on-screen. The combat model now emphasizes active hit windows, spacing, facing, recovery punishment, defensive movement, and reset-after-score point sparring rather than health-bar fighting.
